# SmartBudget Manager

## Software Description
This product is an Excel workbook called **SmartBudget Manager** that is used to track income and expenses, calculate budgets, and receive a warning when the budget limit is exceeded.

## Functional Requirements
* **Software:** Microsoft Excel (2016, 2019, 2021, Microsoft 365) or an equivalent compatible spreadsheet application.
* **User Skills:** Basic Excel knowledge, including basic cell manipulation and reading pie charts.

## Getting Started
1. Open the **SmartBudget Manager** workbook in Excel or any compatible spreadsheet software.
2. **Categories Worksheet:** Fill in each expense category, add a short description, and enter its budget. The total budget is calculated automatically.
3. **Transactions Worksheet:** Enter the transaction date, a brief description, the category (`Income` or `Expense`), the amount, and an optional note.
4. **Dashboard Worksheet:** View the complete summary of your monthly budget and visual breakdown.
