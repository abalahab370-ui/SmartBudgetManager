README_SmartBudget Manager :
SOFTWARE DESCRIPTION:
This product is an Excel workbook called SmartBudget Manager that is used to track income and expenses,calculate budget,and receive a warning when the budget limit is exceeded.

Functional requirements:
This product requires owning excel(Microsoft Excel 2016, 2019, 2021, Microsoft 365, or an equivalent compatible version) and knowing some basic functionality(basic cell manipulation,basic excel knowledge,pie chart understanding).

GETTING STARTED:
●	open the SmartBudget Manager in excel or any other software.
●	In the categories worksheet,fill in the expense category,add a small description for it,and put its budget.A total budget will be automatically counted. 
●	In the transaction worksheet,fill in the date of the transaction,a small description,choose its category(income/expense),put its amount,add a note.
●	Use the dashboard worksheet to see the complete summary of the monthly budget.
